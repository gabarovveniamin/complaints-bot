# 🛡️ Анонимный бот оперотряда общежития

Telegram-бот для приема жалоб, сообщений о нарушениях и происшествиях в общежитии с возможностью отправки в закрытую группу оперотряда.

---

## 🚀 Возможности

1. **Строгая анонимность**:
   - При отправке в группу используется метод `copy_message`, исключающий пересылку с указанием автора.
   - Личные данные (ID, имя, username) автора жалобы не раскрываются.
2. **Поддержка любых форматов**:
   - Текстовые сообщения.
   - Фотографии, видео и кружочки.
   - Голосовые сообщения и документы.
3. **Локальный архив (SQLite)**:
   - Каждому обращению присваивается уникальный номер (например, `#0001`).
   - Если группа не настроена, обращения всё равно сохраняются в базу данных `appeals.db`.
4. **Удобная привязка группы**:
   - Команда `/id` позволяет моментально узнать ID любой группы или чата для настройки.

## ⚙️ Установка и запуск

1. **Установка зависимостей** (если ещё не установлены):
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка токена и группы** в файле `.env`:
   ```env
   BOT_TOKEN=your_bot_token_here
   GROUP_CHAT_ID=
   ```

3. **Запуск бота**:
   - Двойным кликом по файлу `run.bat`
   - Или командой в терминале:
     ```bash
     python bot.py
     ```

## 📢 Как подключить отправку в группу оперотряда

1. Добавьте бота в нужную группу Telegram (где сидят сотрудники оперотряда/дежурные).
2. Напишите в этой группе команду:
   ```
   /id
   ```
3. Бот ответит ID группы (обычно начинается с `-100...`).
4. Скопируйте этот номер и вставьте в `.env`:
   ```env
   GROUP_CHAT_ID=-1001234567890
   ```
5. Перезапустите бота. Теперь все входящие жалобы будут автоматически поступать в группу с порядковым номером и временем.
